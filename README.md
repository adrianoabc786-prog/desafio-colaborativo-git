# desafio-colaborativo-git
Sistema desenvolvido em linguagem C com o objetivo de praticar conceitos fundamentais de programação. O projeto  vai permitir realizar o cadastro e gerenciamento de produtos, utilizando estruturas de dados, funções, entrada e saída de informações e operações básicas de controle. Apresentando no arquivo do codigo do projeto.

Vale ressaltar que esse tipo de sistema é muito utilizado tanto em empresas quanto comércios. Pois sempre tem a entrada e saída de novas informações relacionada a produtos e clientes.

Tecnologias: C • GCC • Git/GitHub
